# Mindmap по конфликтам — сайт

Итоговый проект, часть 1 (курс «Переговоры», Центральный университет). Интерактивный mindmap по теории конфликтов в неоновом стиле.

## О проекте

Это первая часть итогового проекта курса «Переговоры». Задание — построить mindmap, который структурирует всю теорию блока «Конфликты» и при этом работает как прикладной алгоритм: что делать, когда конфликт вот-вот начнётся или уже начался.

Карта построена только на материалах курса (презентации воркшопов Soft Skills Lab) и состоит из веток:

- **Основа** — ключевые понятия: конфликт, социальная роль, манипуляция, лестница конфликтов;
- **Предотвращение конфликта** — аудит негатива и три права человека при общении;
- **Как думать в конфликте** — анализ до ответа: тема на переговоры, декодирование, тип конфликта, цель на конфликт, выбор этапа;
- **Этапы конфликта 1–4** — обработка эмоций, показ границ, защита границ, сепарация/эскалация. У каждого этапа есть критерии входа и выхода, приёмы и шаблоны фраз.

### Зачем это нужно

- **Систематизировать теорию.** Все понятия курса собраны в одну структуру, где видно, что из чего состоит и как понятия связаны между собой.
- **Иметь алгоритм под рукой.** Карта читается как последовательность шагов: проанализировать фразу собеседника, поставить цель на конфликт, выбрать этап по критериям входа, подобрать приём и шаблон.
- **Подготовиться к устной защите.** На защите нужно, опираясь на mindmap, поставить цель на конфликт по кейсу, выбрать этап и приём и сформулировать ответ манипулятору. Сайт позволяет быстро найти нужную ветку через поиск.

### Почему сайт, а не файл

Сайт открывается по ссылке на любом устройстве и ничего не требует устанавливать. Ветки раскрываются по клику, поэтому большую карту (почти 300 узлов) удобно читать по частям. Шаблоны фраз, входы и выходы этапов и типичные ошибки выделены цветом.

## Что внутри

```
index.html          — страница
assets/style.css    — стили
assets/app.js       — интерактивный mindmap (без библиотек)
assets/data.js      — данные карты (сгенерированы из mindmap.md)
assets/fonts/       — шрифты Oswald, Montserrat, Pacifico (лицензия OFL)
mindmap.md          — исходная структура карты (текстом)
```

Сайт статический, сборка не нужна. Проверить локально: открыть `index.html` в браузере.

## Публикация на GitHub Pages

```bash
git init
git add .
git commit -m "Mindmap по конфликтам"
git branch -M main
git remote add origin https://github.com/<логин>/<репозиторий>.git
git push -u origin main
```

Затем на GitHub: **Settings → Pages → Build and deployment → Source: Deploy from a branch → Branch: `main`, папка `/ (root)` → Save**.
Через 1–2 минуты сайт откроется по адресу `https://<логин>.github.io/<репозиторий>/`. Репозиторий должен быть публичным (на бесплатном аккаунте).

## Как поменять содержимое карты

Карта рисуется из `assets/data.js`. Проще всего править JSON прямо в нём: каждый узел — это `{"t": "текст", "c": [дети]}`.

Подсветка узлов работает автоматически по началу текста:
- `«…»` или `Шаблон…` — шаблон фразы (пунктирная рамка);
- `Вход…` — вход на этап (бирюзовый);
- `Выход…` — выход с этапа (розовый);
- `Ошибка…` — типичная ошибка (красный).
