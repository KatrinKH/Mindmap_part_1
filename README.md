# Mindmap по конфликтам — сайт

Итоговый проект, часть 1 (курс «Переговоры», Центральный университет). Интерактивный mindmap по теории конфликтов в неоновом стиле.

## О проекте

Это первая часть итогового проекта курса «Переговоры». Задание — построить mindmap, который структурирует всю теорию блока «Конфликты» и при этом работает как прикладной алгоритм: что делать, когда конфликт вот-вот начнётся или уже начался.

Карта построена только на материалах курса (презентации воркшопов Soft Skills Lab) и состоит из веток:

- **Основа** — ключевые понятия: конфликт, социальная роль, манипуляция, лестница конфликтов;
- **Предотвращение конфликта** — аудит негатива и три права человека при общении;
- **Как думать в конфликте** — анализ до ответа: тема на переговоры, декодирование, тип конфликта, цель на конфликт, выбор этапа;
- **Этапы конфликта 1–4** — обработка эмоций, показ границ, защита границ, сепарация/эскалация. У каждого этапа есть критерии входа и выхода, приёмы и шаблоны фраз.

### Зачем это нужно

- **Систематизировать теорию.** Все понятия курса собраны в одну структуру, где видно, что из чего состоит и как понятия связаны между собой.
- **Иметь алгоритм под рукой.** Карта читается как последовательность шагов: проанализировать фразу собеседника, поставить цель на конфликт, выбрать этап по критериям входа, подобрать приём и шаблон.
- **Подготовиться к устной защите.** На защите нужно, опираясь на mindmap, поставить цель на конфликт по кейсу, выбрать этап и приём и сформулировать ответ манипулятору. Сайт позволяет быстро найти нужную ветку через поиск.

### Темы оформления

При входе на сайт открывается стартовый экран, где можно выбрать оформление:

- **GTA 6** — неоновый Майами: кинематографичное открытие, параллакс пальм и города, огни машин на мосту, блики на воде, плакатные карточки и неоновое мерцание при наведении;
- **Atomic Heart** — ретрофутуризм: загрузка в стиле старого терминала, плакатная композиция, глитч заголовка, мигающие индикаторы, линия сканирования, роборука, асимметричная сетка, красные плашки разделов и механическое появление блоков;
- **Resident Evil Requiem** — кинематографичный хоррор: проявление из темноты, тонкая разреженная типографика, холодный синий свет, медленное появление текста, лёгкое дрожание камеры, видеопомехи и редкие красные вспышки.

Если в системе включено «Уменьшение движения», анимации отключаются автоматически.

Содержание во всех темах одинаковое. Тему можно сменить в любой момент кнопкой «Тема» в верхнем меню. Ссылка с параметром `?theme=gta`, `?theme=atomic` или `?theme=re` сразу открывает сайт в нужной теме, без стартового экрана.

Оформление вдохновлено эстетикой игр и не связано с их правообладателями.

#### Как включить, выключить тему или поставить заглушку

Каждая тема лежит в отдельной папке, а управляются они из одного файла `assets/themes/config.js`:

```js
window.MM_THEME_CONFIG = {
  gta:    "on",   // GTA 6
  atomic: "on",   // Atomic Heart
  re:     "on"    // Resident Evil Requiem
};
```

- `"on"` — тема включена;
- `"soon"` — заглушка: карточка видна на стартовом экране с пометкой «Скоро», но выбрать её нельзя;
- `"off"` — тема скрыта, её файлы не загружаются.

Порядок строк задаёт порядок карточек, первая включённая тема — тема по умолчанию. Если включена только одна тема и заглушек нет, стартовый экран и кнопка «Тема» не показываются.

Чтобы вырезать тему из сайта совсем, удалите её папку и строку `<script src="assets/themes/<имя>/theme.js">` в `index.html`.

В `theme.js` у темы могут быть необязательные функции `onEnter()` (вызывается, когда пользователь входит в тему; например, загрузочный терминал Atomic Heart) и `onLeave()` (при смене темы). Элементам сцены можно задать `data-depth` — силу параллакса при прокрутке и движении мыши.

Чтобы добавить новую тему, скопируйте папку любой темы, поменяйте внутри `id` (и селекторы `data-theme="…"` в `theme.css`), подключите её `theme.js` в `index.html` и добавьте строку в `config.js`.

### Почему сайт, а не файл

Сайт открывается по ссылке на любом устройстве и ничего не требует устанавливать. Ветки раскрываются по клику, поэтому большую карту (почти 300 узлов) удобно читать по частям. Шаблоны фраз, входы и выходы этапов и типичные ошибки выделены цветом.

## Автор

Имя автора задаётся в одной строке в начале файла `assets/app.js`:

```js
const AUTHOR = "Имя Фамилия";
```

Оно автоматически появится на стартовом экране, в подвале сайта и в справке.

## Что внутри

```
index.html          — страница (стартовый экран, сцены тем, разделы, справка)
assets/style.css    — базовые стили, все цвета вынесены в переменные
assets/fonts.css    — подключение шрифтов
assets/themes/
  config.js         — какие темы включены (on / soon / off)
  gta/              — тема GTA 6
    theme.js        —   название, описание, карточка, сцена главного экрана
    theme.css       —   все стили темы
  atomic/           — тема Atomic Heart (такая же структура)
  re/               — тема Resident Evil Requiem (такая же структура)
assets/app.js       — автор, эффекты (появление, параллакс), стартовый экран, интерактивный mindmap
assets/data.js      — данные карты (сгенерированы из mindmap.md)
assets/fonts/       — шрифты Oswald, Montserrat, PT Mono, а также Pacifico (GTA 6) и Russo One (Atomic Heart); лицензия OFL
mindmap.md          — исходная структура карты (текстом)
```

Сайт статический, сборка не нужна. Проверить локально: открыть `index.html` в браузере.

## Публикация на GitHub Pages

```bash
git init
git add .
git commit -m "Mindmap по конфликтам"
git branch -M main
git remote add origin https://github.com/<логин>/<репозиторий>.git
git push -u origin main
```

Затем на GitHub: **Settings → Pages → Build and deployment → Source: Deploy from a branch → Branch: `main`, папка `/ (root)` → Save**.
Через 1–2 минуты сайт откроется по адресу `https://<логин>.github.io/<репозиторий>/`. Репозиторий должен быть публичным (на бесплатном аккаунте).

## Как поменять содержимое карты

Карта рисуется из `assets/data.js`. Проще всего править JSON прямо в нём: каждый узел — это `{"t": "текст", "c": [дети]}`.

Подсветка узлов работает автоматически по началу текста:
- `«…»` или `Шаблон…` — шаблон фразы (пунктирная рамка);
- `Вход…` — вход на этап (бирюзовый);
- `Выход…` — выход с этапа (розовый);
- `Ошибка…` — типичная ошибка (красный).
